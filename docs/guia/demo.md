# Demo

{% embed url="https://elmiguelki.github.io/neoskins-viewer/demo/" %}

Pulsa la tarjeta para abrir la demo en una pestaña nueva.

## Cómo usarla

{% stepper %}
{% step %}
### Carga un jugador

Escribe un nombre y pulsa **Cargar**. Aparecen la skin y la capa que el servidor NEO tiene para ese nombre.
{% endstep %}

{% step %}
### Prueba una capa

En **NEOCapes** salen las capas visibles para ese jugador. Las animadas se reproducen.
{% endstep %}

{% step %}
### Cambia el render

Apaga y enciende **Contorno** y **Antialiasing** para ver la diferencia.
{% endstep %}

{% step %}
### Lanza una animación

Cada botón de **Animaciones** dispara un gesto. Al terminar, el modelo vuelve solo al reposo.
{% endstep %}
{% endstepper %}

También puedes previsualizar un PNG o un GIF de tu equipo con **Skin desde archivo**. No se sube a ningún sitio.

{% hint style="info" %}
La demo es una sola página HTML que usa el archivo único de [Descargas](descargas.md). Su código está en la carpeta `site-src/demo` del repositorio y sirve como punto de partida.
{% endhint %}
